# A simple monopole propagator
The monopole class, defined in **Monopole.py**, provides an easy and convenient way to treat the propagation of a magnetic monopole in a magnetic field.

## The object-oriented approach
Instead of using multiple functions to propagate the monopole across the space, we instead create a new data object to represent our particle, 
and make the propagation a method of this class. In this way, the same monopole can be propagated for different conditions with minimal changes to code.
